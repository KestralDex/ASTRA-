# ASTRA Accessibility & UI Verification Checklist

Use this checklist during the final UI/UX pass.

## Required checks

- [ ] Text/background contrast is readable in the chosen Streamlit theme.
- [ ] Charts remain understandable without relying only on color.
- [ ] Chart titles and axis labels are descriptive.
- [ ] Meaningful images have accessible text/captions when images are introduced.
- [ ] Forms have visible labels.
- [ ] Keyboard-only navigation is tested for filters, selects, forms and buttons.
- [ ] Focus order remains logical.
- [ ] No flashing, rapidly animated, or distracting UI is introduced.
- [ ] Error messages explain the problem without exposing secrets or internal paths.
- [ ] Important model limitations are readable and not hidden behind styling.
- [ ] Human-review controls use clear, non-coercive language.
- [ ] Layout is tested on the presentation laptop/projector resolution.
