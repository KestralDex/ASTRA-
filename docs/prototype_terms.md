# ASTRA Prototype Terms of Use

ASTRA v0.1 is an academic and research decision-support prototype.

By using the prototype, users acknowledge that:

1. Model outputs are estimates derived from historical data and may be wrong.
2. Scenario results show how the current trained model responds to changed inputs; they do not prove causation.
3. ASTRA v0.1 does not execute procurement, routing, inventory, supplier, financial, or other operational actions.
4. A human reviewer remains responsible for any downstream decision.
5. Users should not enter passwords, API keys, confidential credentials, or unnecessary personal information into the prototype.
6. The prototype is not presented as production-ready, enterprise-certified, or guaranteed to be secure, available, or accurate.
7. Dataset and third-party software licensing must be respected before redistribution or deployment.
